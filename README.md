Welcome to splitora
steps to run the project - 
1. mvn clean build
2. update the application.properties file 
  spring.datasource.username=**username** (replace it with your mysql localhost username)
  spring.datasource.password=**password**. (replace it with your mysql localhost password)
3. Open MySql workbench run data.sql file present in resources folder
4. Run the SplitoraApplication.java class
5. open the http://localhost:8080/swagger-ui/index.html in any browser
